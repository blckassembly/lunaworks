# Alumni Truck — X-Brace EV Concept

A boxy cyber G-Wagon built around an **exposed X-brace frame** — the same structural language as the Lunar Works rover, applied to a road vehicle.

- Doors are open structural frames with a visible X-brace cross pattern (dark graphite), glass set into the frame
- Slab-flat front, no grille, vertical corner light elements
- Continuous black glass canopy band
- Silver-white panels visibly bolted over the dark frame — rivets, exposed hinges
- Oversized all-terrain tires, deep-dish wheels, tall ride height, roof rack with pod

Hero vehicle for the Alumni OS driving simulation (separate project).
