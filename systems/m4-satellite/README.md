# M4 — Stacked-Module Satellite

A spacecraft built as a vertical stack of separable ring modules on a CFRP + titanium central spine. Each module is an independent assembly with its own material, mass, and manufacturing method.

## Module stack

| Assembly | Material | Mass (kg) | Method |
|---|---|---|---|
| Central spine | CFRP + Ti | 600 | Filament wound |
| Optical module (0.8 m telescope) | SiC + CFRP | 520 | Precision machined |
| IR cryo module | Aluminium | 450 | Brazed cryo |
| RF module | Al + RF | 340 | CNC |
| Laser / LIDAR module | Ti | 310 | 5-axis |
| Avionics | Shielded Al | 330 | Modular trays |
| Power (xenon tanks, Hall + monoprop thrusters) | Mixed | 520 | Integrated |
| Propulsion | Composite + Ti | 750 | Tank weldment |
| Solar arrays (GaAs, 32 m span) | GaAs | 620 | Panel assembly |

**Total wet mass: ~4,800 kg.** Reaction wheels on isolation mounts, bipod isolators with launch locks, deployable radiators, GEO-mirror orbit configuration shown in the blueprint.
