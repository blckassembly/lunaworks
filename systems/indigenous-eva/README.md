# Indigenous EVA System — Equipment, Not Clothing

A modular EVA suit architecture that replaces the single rigid pressure shell with **distributed life support**, so failure is contained locally instead of cascading system-wide.

## Architecture

- **Backpack** — distributed tanks, no single backpack dependency
- **Vest** — central hub
- **Helmet** — autonomous sensor node (below)
- **Arms** — autonomous, isolatable pressure zones
- **Legs** — continuous pressure, fabric-dominant for low joint resistance

## Principles

- **Survivability first:** limb isolation, independent pressure zones, passive safety, no single-point failure
- **Mobility = endurance:** natural movement lowers metabolic cost and oxygen burn
- **Manufacturable by design:** additive composite frames, field-replaceable modules, standardized interfaces that scale to fleet production
- **Environments:** LEO operations, lunar surface, planetary exploration

## The helmet

Additively manufactured titanium shell (DMLS/SLS) carrying a forward short-range LiDAR + radar/UWB array, a multi-spectral camera and sensor ring, HUD with life-support data, thermal radiators, and composite armor plates — over a sacrificial ALON/sapphire outer shield and an impact-resistant polycarbonate/gold visor. Seal-lock neck ring carries the pressure, oxygen, and data interfaces. Sized Large / Medium / Small.
