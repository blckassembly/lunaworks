# Container Hospital — Modular Field Hospital

A two-story field hospital built from 40-ft containers.

- **Covered intake/triage** under a solar canopy, ambulance bay at grade
- **Ground floor:** emergency treatment; **upper floor:** wards, waiting/diagnostics, sanitation
- **Power:** rooftop "solar leaf array" — a flower-form solar collector on a central mast — plus containerized HVAC
- Deployable as a self-contained medical module anywhere containers can be delivered
