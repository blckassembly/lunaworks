# Latimer-X "Kong" — FSD SoC Architecture

A full-self-driving system-on-chip architecture.

- **Dual NPUs — 100 TOPS each**
- **GPU — 30+ TFLOPS**, with AI & SFU block
- **Dual CPU clusters** — 4× Cortex-A78 + 4× Cortex-A55 each
- **LPDDR5 — 128 GB per chip**
- **Sensor fusion & IMU** — ultrasonic, radar, SAR, GPS, LiDAR, camera, LEO inputs
- Dedicated **security** and **safety** partitions
- 24-bit ISP, H.265 video encoder
